\section*{Viral HRSM Branch Charter}

This branch tests whether viral populations occupy structured adaptive state spaces under mutation, immune pressure, treatment, bottlenecking, and host ecology.

The object of analysis is not a single virion. The object is a viral population, lineage, infection trajectory, quasispecies cloud, or experimental passage series.

\[
\phi_v(t) = [H_v(t), R_v(t), S_v(t), M_v(t)].
\]

\(H_v\) is adaptive reserve.
\(R_v\) is rebound or recoverability.
\(S_v\) is swarm coherence.
\(M_v\) is retained evolutionary memory.

The first computational target is SARS-CoV-2 persistent infection. HIV is reserved for Phase II because it is biologically deeper but technically messier.

The central test is whether a memory model predicts persistence, rebound, escape, or lineage re-emergence better than a current-state model.
